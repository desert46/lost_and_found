About

This webapp focuses on the lost proptery system at BHS. The goal of this webapp is to digitise the current lost property system. The webapp can be used by students to upload property they have found or to upload requests to retrieve an item they have lost

How to use

If you have found an item, simply visit the Upload page and fill in the details of the item. Include as many extra details in the notes section as possible. Then hand the lost and found item to the student office as soon as possible.


If you have lost an item, simply visit the Find page and fill in the details of the item. Include as many extra details in the notes section as possible. An admin will update you on the status of the lost item as soon as possible. You may be required to input more information on your item. You can do this by pressing edit on any item and updating the notes section with additional details. You may have to wait several days for a response.

How to use Admin Panel

The admin panel allows you to edit any item in the database by pressing the Edit button. If you want to return an item to a student, press the Match button to select an item that a student is looking for. Then simply press the Return button on the respective item that has been found. This will pair the items and send an email to the student notifying them that their property has been found. To request more info on an item, press the Match button to select the item then press Request Info. This will send an email to the student asking for more information about the item.


To manage accounts, go to the Manage page to view all of the active accounts. Here you will be able to Demote or Promote a user by pressing the respective buttons. Every user starts off as a Member with Level 2 clearance. They may be demoted down to clearance Level 3 which signifies a disabled account that will denied service from the website. Users may also be promoted up to Level 1 clearance signiying an admin. Admins will have access to the admin panel and account manager and will be expected to manage the BHS Lost Property System. You may not demote or promote yourself.
